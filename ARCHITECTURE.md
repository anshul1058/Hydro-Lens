## Pipeline Stages

### 1. Image Acquisition
- **Source:** USB microscope (100×–1000×), smartphone + clip-on lens, or pre-captured dataset images
- **Format:** RGB, 8-bit per channel, typical 1920×1080 or higher
- **Lighting:** Bright-field or fluorescence (model trained on both)

### 2. Preprocessing (`src/preprocess.py`)
| Step | Method | Parameters | Purpose |
|------|--------|------------|---------|
| Denoise | Median blur | kernel=3×3 | Remove salt-and-pepper noise from sensor |
| Contrast | CLAHE | clipLimit=2.0, tileGridSize=(8,8) | Enhance local contrast, preserve natural color |
| Resize | Letterbox | 640×640 (YOLO input) | Maintain aspect ratio, pad with gray (114) |

**Output:** Clean color image at 640×640, ready for inference.

### 3. Detection (`src/detect.py`)
- **Model:** YOLOv8n (3.2M params, ~6 MB), fine-tuned on microplastics datasets
- **Input:** 640×640 RGB tensor, normalized to [0,1]
- **Output per image:**
  - List of detections: `[x_center, y_center, width, height, confidence, class_id]`
  - Classes: `0: fragment`, `1: fiber`, `2: film`, `3: foam`, `4: pellet` (extensible)
- **Inference config:**
  - `conf_threshold=0.25` (low to catch candidates)
  - `iou_threshold=0.45` (NMS)
  - `max_det=300`

### 4. Sizing (`src/size.py`)
For each bounding box, compute physical size using calibration factor (µm/pixel):

| Metric | Formula | Use Case |
|--------|---------|----------|
| **Feret's diameter (max)** | `max(distance between parallel tangents)` | Longest dimension, standard for irregular particles |
| **Feret's diameter (min)** | `min(distance between parallel tangents)` | Shortest dimension |
| **Equivalent Circular Diameter (ECD)** | `2 × sqrt(area / π)` | Comparable to sieve analysis |
| **Aspect ratio** | `Feret_max / Feret_min` | Shape classification (fiber vs fragment) |

**Implementation:** OpenCV `minAreaRect` on contour from masked bounding box region.

### 5. Calibration Integration (`src/calibrate.py`)
- Calibration factor (µm/pixel) loaded from JSON (generated by calibration routine)
- Applied to all size metrics before reporting
- **Flag raised** if calibration missing or stale (> 7 days)

### 6. Confidence Scoring (`src/confidence.py`)
```
Sample Confidence = mean(detection_confidences) × calibration_quality × coverage_factor
```
- `detection_confidence`: YOLO output per box (0–1)
- `calibration_quality`: 1.0 if valid calibration, 0.5 if missing/stale
- `coverage_factor`: 1.0 if image covers ≥ 1 mm², else proportional

### 7. Results Report
Structured JSON + human-readable Streamlit dashboard:
```json
{
  "sample_id": "SL-20260925-001",
  "timestamp": "2026-09-25T14:32:10Z",
  "calibration": {"factor_um_per_px": 0.42, "valid": true, "date": "2026-09-24"},
```

## Data Flow Summary

1. **User uploads image** → Streamlit validates format
2. **Preprocess** → 640×640 tensor
3. **YOLOv8n** → bounding boxes + confidences
4. **Calibration check** → load µm/px factor
5. **OpenCV sizing** → physical dimensions per particle
6. **Confidence aggregation** → sample-level score
7. **Report generation** → JSON + UI

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| YOLOv8n (not segmentation) | Speed + size; bounding boxes sufficient for count/size |
| CLAHE not histogram equalization | Preserves color for fluorescence channels |
| Feret's diameter + ECD | Covers both regulatory (ECD) and morphology (Feret) needs |
| Mandatory calibration gate | Prevents false quantitative claims |
| Optional polymer ID | Scope control — core promise is screening, not identification |
